Waterfall SDLC Model

1. Requirements Analysis

▼

Define calculator features: Basic arithmetic (+, -, *, /), number buttons (0-9), decimal point, clear button, equals button, and a display area. Specify expected behavior for inputs and calculations.

2. System Design

▼

Plan the UI layout: Grid for buttons, display at the top. Design the HTML structure (divs for display, buttons). Plan the JavaScript logic: How to handle number/operator clicks, update the display, store intermediate values, and perform calculations.

3. Implementation (Coding)

▼

Write the code: Create the calculator.html file with divs and buttons. Write calculator.css for styling the layout, display, and buttons. Write calculator.js to add event listeners to buttons and implement the calculation logic and display updates.

4. Testing (Verification)

▼

Test functionality: Verify all number and operator buttons work. Test calculations (e.g., 2+2=4, 5*3=15, 10/2=5). Test edge cases like division by zero, consecutive operators, clearing the display, and using the decimal point correctly.

5. Deployment (Installation)

▼

Make the calculator accessible: Place the calculator.html, calculator.css, and calculator.js files in the correct folders. Ensure the link from the waterfall page (index.html) points correctly to calculator.html.

6. Maintenance

▼

Address issues and improve: Fix any bugs discovered after deployment (e.g., calculation errors). Potentially add new features like backspace, or more advanced operations based on feedback.
